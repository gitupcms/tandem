# Agent skills

Instructions for coding agents (Claude Code skills format) that work on an app using Tandem. Copy a folder into your project's `.claude/skills/`, or point your agent at the `SKILL.md`.

| Skill | Use it to |
| --- | --- |
| `tandem-start` | add Tandem to a Swift + Kotlin app and get the first shared journey green |
| `tandem-explore` | walk the app through its host and map screens, state and actions |
| `tandem-cover` | write journeys for actions and outcomes no journey checks yet |
| `tandem-check` | run the journeys and find out which side broke |
